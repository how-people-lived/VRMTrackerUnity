VRMTracker — モーション (.vrma) フォルダ
=========================================

このフォルダに VRM Animation 形式（拡張子 .vrma）のモーションファイルを置くと、
アプリのインスペクタ「モーション」セクションに一覧表示され、ワンタッチで再生できます。
（インスペクタの「モーション(.vrma)を読み込む」ボタンから任意の場所のファイルも再生可）

■ .vrma とは
  VRM コンソーシアムが策定した、VRM 向けのオープンなモーション標準フォーマットです。
  Humanoid ボーンにリターゲットされるため、どの VRM アバターでも再生できます。

■ 無償・再配布可能なモーションの入手先（例）
  - VRM 公式サイト（vrm.dev）の「VRM Animation」サンプルモーション
  - VRM コンソーシアムが GitHub で配布する .vrma サンプル
      https://github.com/vrm-c/vrm-specification  ほか
  ※ 各モーションの配布条件（ライセンス）は必ず個別にご確認ください。
    「無償配布かつ再配布可」のものだけを同梱・共有してください。

■ 使い方
  1. 入手した .vrma ファイルをこのフォルダ（StreamingAssets/Motions/）に入れる
  2. アプリを起動 → VRM を読み込む
  3. インスペクタ「モーション」で該当モーションの ▶ ボタンを押す
     （「一覧更新」で再スキャン、「停止」で解除して通常のトラッキングに戻る）

※ 本リポジトリにはモーションファイルは同梱していません（配布条件の確認が必要なため）。
  上記の無償・再配布可のファイルをご自身で入手して配置してください。
